Open-source AI repos worth a look, logged as they turn up

Three times a day a small Python bot searches GitHub for recently updated repositories on agents, RAG, MCP and LLM tooling, skips anything it has already logged, and adds one new find to this list. I use it to keep up without scrolling feeds.

    How it works

    About 180 lines of Python and three workflows.

    Search
    Eight GitHub search queries by topic with a star floor, for example topic:rag stars:>500 and topic:mcp stars:>300, sorted by most recently updated.
    Pick
    The bot takes the first result it hasn’t logged before, so each run adds at most one repo.
    Schedule
    Runs at 00:00, 08:00 and 16:00 UTC. A monthly job tidies the log.
    Pipeline
    GitHub Actions cron → GitHub search API → README log → JSON → GitHub Pages
